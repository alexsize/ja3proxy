# Техническая документация JA3Proxy

Нормативное техническое задание:

- [ТЗ на TLS Recorder и центр управления, версия 2](JA3Proxy_Fingerprint_Recorder_TZ_v2.md)
- [Текущее состояние recorder, ограничения и проверки](RECORDER_IMPLEMENTATION.md)
- [Контракт локального API](recorder-openapi.json)

Версия 2 сохраняет исходную концепцию «входящие raw-данные → нормализованный
профиль → исходящие raw-данные → различия», но формализует границы релизов,
точки захвата, алгоритмы fingerprints, маршрутизацию, безопасность,
отказоустойчивость и критерии приёмки.

Перед началом каждого релиза из раздела 103 должны быть подготовлены:

1. матрица трассируемости требований;
2. контракт OpenAPI для затрагиваемых методов;
3. схема данных и план миграций для затрагиваемых сущностей;
4. приёмочные тесты и описание происхождения тестовых данных;
5. изменение модели угроз и план измерения производительности.
